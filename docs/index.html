Sécurité

Analyse de sécurité — cible : Prépare une landing page sur les agents autonomes. Tu dois utiliser le Research Agent pour obtenir les informations nécessaires.

Contrôles appliqués :
  [01] Authentification       Chaque appel mutateur exige une clé d'API (X-API-Key) ; 401 sinon.
  [02] Autorisation           Le registre refuse la délégation sans clé opérateur.
  [03] Transport              TLS/HTTPS obligatoire hors réseau de confiance du lab.
  [04] Entrées                Validation et longueur maximale du prompt (anti-injection).
  [05] Journalisation         Chaque délégation est horodatée et traçable dans /events.
  [06] Surface                Les agents n'exposent que 4 endpoints : pas de surface superflue.
  [07] Défense en profondeur  L'orchestrateur ne connaît pas le code des agents.
  [08] Secrets                Aucune clé n'est renvoyée dans les réponses HTTP.

Risques résiduels : un agent compromis reste un pair de confiance dans le LAN ; prévoir mTLS et un registre de clés tournantes hors du lab.
